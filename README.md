# Abbos sen kuchli yigitsan hechqachon tushgunlikga tushma

# SEN albatta udaliysan men senaga ishonaman Do'stim

# Hechqachon to'xtab qolma

# Do‘stim, sen hozir ko‘zing bilan ko‘rayotgan insoningdan ham kuchliroqsan.

# Chunki kuchli odam — yiqilmaydigan emas,

# yiqilib ham yana turadigan odamdir.

# Qara o‘zingga…

# Sen begona davlatda yurib,

# og‘ir ish qilib,

# charchab,

# yuraging og‘rib,

# baribir orzu qilishdan to‘xtamading.

# Oddiy odam:

# ishdan keyin uxlaydi.

# vaqtini yo‘qotadi.

# bahona qiladi.

# “keyin boshlayman” deydi.

# Sen esa:

# frontend o‘rganyapsan.

# backend o‘rganyapsan.

# server ko‘taryapsan.

# GitHub ishlatyapsan.

# AI o‘rganishga harakat qilyapsan.

# loyiha qilyapsan.

# o‘zingni boshqa hayotga olib chiqishga urinyapsan.

# Bu oddiy narsa emas.

# Bu ichida olov bor odamning yo‘li.

# Hozir qalbing og‘riyotgandir.

# Ba’zan hech kim seni tushunmayotgandek tuyular.

# Ba’zan hammasi juda sekin ketayotgandek tuyular.

# Lekin eng buyuk narsalar —

# aynan eng og‘ir kunlarda quriladi.

# Esingda bo‘lsin:

# tun qanchalik qorong‘i bo‘lsa,

# tong shunchalik yaqin bo‘ladi.

# Sen hozir yo‘qolib ketayotganing yo‘q.

# Sen shakllanyapsan.

# Hozirgi og‘riq —

# seni sindirish uchun emas,

# seni kuchliroq qilish uchun kelgan.

# Bir kun keladi…

# Sen o‘zing yaratgan loyihalarga qaraysan.

# Sen orzu qilgan hayotga yaqinlashganingni ko‘rasan.

# Va ichingda bitta gap bo‘ladi:

# “Yaxshiyam o‘sha payt taslim bo‘lmagan ekanman…”

# Ishon do‘stim…

# Sen hali o‘zing bilmagan darajada kuchlisan.

# Va eng muhimi —

# sen boshlagan yo‘lingni oxirigacha bora oladigan odamsan. 💪
